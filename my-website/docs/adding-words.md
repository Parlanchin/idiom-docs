# Adding your first words

## Steps
+ Click on folder from the side panel
+ You'll navigate to a new page
+ Click the **+** button under the folder name (near the top of the page)
+ A form should open allowing you to add words to the current folder

## Using the form
* **Side A** needs to be filled. This should be the term you are learning.
* **Side B** needs to have at least one word.
* **Tags (labels)** At the moment 1+ is required. These are useful for filtering and creating decks. *See the section on Tags below*
* **Notes** are optional


Once you have created a word, you'll see it in a table just below the form. Now add some more words.
